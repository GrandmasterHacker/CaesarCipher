*CaesarCipher*

A simple Python implementation of the Caesar cipher encryption algorithm.

*Usage*
Run the script:
```
python CaesarCipher.py
```

*Features*

1.Encrypts text with a shift key

2.Decrypts text back to original

*Example*
Input:  HELLO
Shift:  3
Output: KHOOR

*Installation*
1.Clone the repository:
```
git clone https://github.com/GrandmasterHacker/CaesarCipher.git
```
2.Navigate into the project folder:
```
cd CaesarCipher
```
